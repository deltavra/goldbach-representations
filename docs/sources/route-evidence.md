## 奇偶层

《按补数素因子个数提取真素数对.md》第 3–9 行取 $`N/3\le p<N/2`$ 的素数 $`p`$。原稿用 $`\Omega`$ 计重数；这里按登记表要求，用 $`\omega`$ 数 $`m=N-p`$ 的**不同**素因子，并独立检查 $`m`$ 的素性。以下 Python 只用标准库。

~~~python
from collections import Counter
from math import log

n = 1_006_274
limit = 2 * n // 3
omega = bytearray(limit + 1)
primes = set()
for p in range(2, limit + 1):
    if omega[p] == 0:
        primes.add(p)
        for m in range(p, limit + 1, p):
            omega[m] += 1

rows = [n - p for p in primes if n <= 3 * p and 2 * p < n]
layers = Counter(omega[m] for m in rows)
even = sum(k for j, k in layers.items() if j % 2 == 0)
odd_composite = sum(k for j, k in layers.items() if j >= 3 and j % 2 == 1)
true_primes = sum(m in primes for m in rows)
powers = sorted(m for m in rows if omega[m] == 1 and m not in primes)
assert len(rows) == 12935
assert (even, odd_composite, layers[1], true_primes) == (6593, 5119, 1223, 1221)
assert powers == [769**2, 811**2]
print(even / layers[1], odd_composite / layers[1])
print(even / true_primes, odd_composite / true_primes)
print(log(log(n)), log(log(2**24)))
~~~

两组分母所得比值依次为 $`5.390842\ldots,4.185609\ldots`$ 和 $`5.399672\ldots,4.192465\ldots`$。$`4.185609\ldots`$ 截到两位是 $`4.18`$，四舍五入是 $`4.19`$。

## 有限差分

《按补数素因子个数提取真素数对》第 59–63 行。

> 对每个 $`N`$，用 $`F_N(h),\ldots,F_N(kh)`$ 形成
> ~~~math
>  T_k(N)=\sum_{i=1}^k(-1)^{i+1}\binom{k}{i}F_N(ih).
> ~~~
> 恒有 $`F_N(0)-T_k(N)=(-1)^k\Delta_h^k F_N(0)`$，故偶数 $`k`$ 给下界，奇数 $`k`$ 给上界。式 (7) 在 $`0<h<\log 2`$ 按 $`k`$ 指数压低渐近误差。例如如果能对每个固定正整数 $`i`$ 证明逐点 $`F_N(ih)=e^{ih}+o_i(1)`$（这里 $`i`$ 是整数指标），就可先令 $`N\to\infty`$，再令 $`k\to\infty`$，得到 $`D_0(N)\sim H_N`$。数值误差的放大系数是 $`\sum_{i=1}^k\binom{k}{i}=2^k-1`$。只要证正性时，(2) 已允许任一 $`0<h<\log2`$ 下预测值的小常量误差。

包含 $`i=0`$ 时，系数绝对值和为 $`2^k`$；把 $`F_N(0)`$ 移到左侧，右边的样本误差乘数为 $`2^k-1`$。登记表以 $`L`$ 表示这里的差分阶数 $`k`$。

## 分布水平

《素数差识别指定偶数的合数补数》第 90–95 行。

> 固定任意 $`B>1`$，取 $`Q=\lfloor\sqrt X/(\log X)^B\rfloor`$。表长为 $`O_B(\sqrt X/(\log X)^{B-1})`$，对每一个预先指定的偶数有
> ~~~math
>               0\le H_N(Q)-R_N
>               \ll_B {\mathfrak S(N)X\log\log X\over(\log X)^3}.       \tag{3d}
> ~~~
> 若能逐个 $`N`$ 把通过项的下界推过 (3d) 的误差上限，即可在中段取得真素数对。按预期的 $`\mathfrak S(N)X/\log^2 X`$ 尺度，这只需要其中 $`O_B(\log\log X/\log X)`$ 的比例，隐含常数须超过误差常数。

《素数差识别指定偶数的合数补数》第 97 行。

> 可直接检验通常的一维下界筛能走到哪一步。对起点素数列筛 $`N-p`$，Bombieri–Vinogradov 给出的分布水平为 $`D=X^{1/2}/(\log X)^C`$。代入上述 $`Q`$ 后，$`s=\log D/\log Q=1+o(1)`$，而下界函数在 $`s\le2`$ 上恒为零。即使把分布水平形式上提高到 $`X^{1-o(1)}`$，$`s`$ 也仅趋于 2，能否产生足够的定量正余量仍须另证。现有的真素数对均方估计控制例外比例，不能给事先选定的单个 $`N`$ 提供这个余量。

## 高斯角权

《半维筛分拆中高斯角的乘法权》第 9–22 行。

> 取 $`h\ge1,\ H=2^h`$，令 $`P_h(t)=\prod_{j=0}^{h-1} C_{2^j}(t)^2`$。单位范数有 $`P_h(1)=1`$。在每个固定的 $`N`$，下式给出真实非单位余因子的总贡献。
>
> **定理一。** 对每个固定的 $`H=2^h`$ 及充分小固定的 $`\delta`$，
> ~~~math
>  \limsup_{\substack{N\to\infty\\2\mid N}}
>  \frac{\sum_{t>1}G_N(t)P_h(t)}{K_N}
>  \ \le C\left\{(a/\delta)^{1/(2H)}-1\right\}.                  \tag{1}
> ~~~
> 同一个 $`C`$ 适用于全部 $`H`$。另一方面，对每个固定 $`H`$ 有
> ~~~math
>  \sum_{t>1}G_N(t)P_h(t)\asymp_H K_N\delta^{-1/(2H)}
>  \qquad(0<\delta<\delta_1(H),\ N\ge N_0(H,\delta)).             \tag{2}
> ~~~
> 所以固定 $`\delta`$ 后增大 $`h`$，非单位贡献的上界为 $`O(K_N\log(a/\delta)/2^h)`$，只需取 $`2^h\ge\log(a/\delta)`$ 并按 (1) 理解 $`N`$ 的阈值。若先固定 $`h`$ 再减小 $`\delta`$，每一个指定偶数的合数补数都给这组测量带来 (2) 的量级。

> 在每格固定区间上使用 Erdős–Turán，频率上限 $`N^{0.025}`$。约分后的模 $`d'`$ 含真素数 $`a>N^{0.499}`$，且不超过 $`aD\le N^{0.515}`$。取与 $`d'`$ 互素的辅助素数 $`N^{0.002}<c\le2N^{0.002}`$。将逆元模转成复合模 $`q_*=d'c`$ 的 $`c-1`$ 个原始逆元相位。此时
> ~~~math
>    N^{0.501}<q_*<N^{0.518},\qquad
>    q_*^{0.7001}<N^{0.499}\le x\le N^{0.5}<q_* .

> 由 Korolev 的 $`\Lambda`$ 前缀和主定理并分部求和，每个素数子段的无权逆元和为 $`O(PN^{-0.016})`$，$`P\le\sqrt N`$。计算所用的净节省为
> ~~~math

~~~python
from fractions import Fraction as F

def saving(x, q, cost):
    return (10 * x - 7 * q) / 74 - q * F("0.0001") - cost

narrow = saving(F("0.497"), F("0.507"), F("0.004"))
smooth = saving(F("0.499"), F("0.518"), F("0.002"))
assert F("0.015") < narrow < F("0.01517") < smooth
print(float(narrow), float(smooth))
~~~
